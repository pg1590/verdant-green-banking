# Acknowledgements and provenance

Verdant's initial portfolio release is derived from the final Green Customer Insights team snapshot (`a73f62cc1b26c9534e85e10ecc389598c6f9f7f2`), developed by Megathon X Team 116. It is published as an independent portfolio edition maintained by Prakhar Gupta.

The original implementation was a five-person collaboration. Prakhar's role was integration and product engineering: contracts, the shared recommendation service, eligibility and ranking, FastAPI, UI, portfolio aggregation, integration/testing and delivery tooling. Data generation, transaction categorisation and impact methods, propensity-model training, and GenAI/Responsible AI were team contributions. The README and portfolio notes describe personal contributions separately from overall project capabilities.

The original MIT notice is preserved in `LICENSE`. Third-party resources retain their respective licences and attribution, documented in `DATA_SOURCES.md` and the font notices. Bank names in source references describe the original use case; this edition has no bank endorsement or affiliation.

Codex and Claude were used as development assistants for implementation, review and debugging. This is distinct from the app's optional runtime explanation providers.

All customer-level examples, screenshots, cached explanation payloads and training data are synthetic. API keys, personal feedback databases, local configuration, team milestone submissions and original Git history are excluded from this release.
