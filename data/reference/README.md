# Runtime reference data

This portfolio edition includes `pvgis/solar_yield_by_region.csv` and the supporting PVGIS response JSON files. The solar engine reads the regional table at runtime. Source settings and attribution are in [DATA_SOURCES.md](../../DATA_SOURCES.md).

Other factors, prices, calibration targets and the cited MCS extract are stored in `config/`. Large third-party workbooks and publications from the original research archive are not redistributed here; their publishers and links are recorded in the data-sources document. The seeded generator and impact engine run from the included configuration and lookup tables.

Customer-level records in `data/sample/` and `data/preview/` are fully synthetic.
